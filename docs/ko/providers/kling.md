# Kling 연결

Kling은 실시간 계정 카탈로그를 통해 이미지 및 동영상 생성 모드를 제공합니다. Atoll은 Kling의 멤버십 및 크레딧 응답도 조회하므로 앱에 남은 크레딧 잔액을 표시할 수 있습니다.

## 목표

설정을 마치면 Kling에서 실시간 카탈로그를 기반으로 이미지와 동영상을 생성할 수 있습니다. Atoll은 Kling이 반환한 남은 크레딧 값을 표시하며, 실행 전 `$` 견적은 제공되지 않습니다.

## 사전 준비

- MCP 연결을 승인할 수 있는 Kling 계정
- 검증된 브라우저 실행 흐름을 위해 macOS에서 실행 중인 Atoll

::: warning
Windows에서 Provider OAuth 연결은 검증되지 않았습니다. 현재 연결 계층은 브라우저를 실행할 때 macOS의 `open` 명령을 호출합니다.
:::

## 단계

1. **Settings → Provider Connections**를 엽니다.
2. **Kling**을 찾아 **Connect**를 선택합니다.
3. 브라우저에서 로그인 및 동의 절차를 완료합니다.
4. 브라우저에 로그인이 완료되었다는 메시지가 표시되면 Atoll로 돌아옵니다.

Kling은 생성, 작업 상태, 계정 크레딧 액세스에 필요한 범위와 함께 PKCE를 사용하는 OAuth를 지원합니다. Kling 계정은 다른 Provider 계정과 독립적입니다.

::: warning
Provider 크레딧이 소모됩니다. Kling MCP는 실행 전 견적을 제공하지 않으므로 제출 전에 `$` 견적이 표시되지 않는 것이 정상입니다.
:::

## 확인

연결한 후 다음을 확인할 수 있습니다.

- Provider Connections에 Kling이 인증된 계정 정보와 함께 **Connected**로 표시됩니다(정보를 사용할 수 있는 경우).
- Atoll은 실시간 `who_am_i` 응답을 읽고 계정별 카탈로그를 캐시합니다. 모델 이름, 매개변수, 멤버십에 따라 사용할 수 있는 항목은 이 페이지에 옮기지 않았습니다.
- 카탈로그는 텍스트-이미지, 이미지-이미지, 텍스트-동영상, 이미지-동영상의 네 가지 모드를 지원합니다. 이 모드는 이미지 또는 동영상 출력 유형으로 정규화됩니다.
- **Refresh balance**는 `query_membership_and_credits`를 호출합니다. Atoll은 멤버십 총량이 아니라 남은 크레딧 필드를 선택한 다음, 그 결과인 크레딧 값을 Settings와 캔버스 잔액 칩에 표시합니다.
- Kling에는 비용 견적 작업이 없습니다. `$` 견적이 없는 것은 정상입니다.

## 미디어 입력 요구 사항

Kling 이미지 입력은 Provider가 액세스할 수 있는 HTTPS URL이어야 합니다. Atoll은 이를 URL 입력으로 전송하므로, 로컬 파일 경로나 로컬 파일 객체를 Kling 어댑터에 직접 전달할 수 없습니다.

이미지-이미지 또는 이미지-동영상 노드에서는 실행하기 전에 미디어에 `https://` URL이 있는지 확인하세요. 텍스트-이미지 및 텍스트-동영상 노드에는 미디어 입력이 필요하지 않습니다.

::: warning
미디어 입력이 있는 제출도 과금 대상입니다. 제출하기 전에 Kling에서 HTTPS URL에 연결할 수 있는지 확인하세요.
:::

## 문제 해결

### 연결에 실패하는 경우

다른 Provider 연결이 브라우저 콜백을 기다리고 있지 않은지 확인하세요. Higgsfield, Magnific, Kling은 로컬 콜백 포트 `17872`를 공유하므로 한 번에 하나의 연결 흐름만 사용할 수 있습니다.

### 멤버십 또는 잔액이 표시되지 않습니다

**Refresh balance**를 선택하세요. Kling의 응답에는 멤버십 및 크레딧 필드가 포함되며, Atoll은 Provider 파서가 선택한 남은 크레딧 값을 표시합니다. 인식 가능한 남은 크레딧 필드가 반환되지 않으면 Provider 응답이 지원되는 형태로 제공될 때까지 잔액을 표시할 수 없습니다.

### 세션이 만료된 경우

만료된 Kling 카드에서 **Reconnect**를 선택하고 브라우저 로그인을 다시 완료하세요. 토큰 갱신에 실패하면 새로운 OAuth 로그인이 필요합니다.

### 미디어 입력이 거부되는 경우

입력에 `https://` URL이 있고 Kling에서 액세스할 수 있는지 확인하세요. 로컬 경로, `http://` URL 또는 사용할 수 없는 URL은 어댑터의 입력 확인을 통과하지 못합니다.

연결, 인증 정보, 콜백을 전반적으로 확인하려면 [문제 해결](/ko/help/troubleshooting)을 참고하세요.
