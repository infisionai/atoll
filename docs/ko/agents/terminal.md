# 에이전트 터미널

Atoll에는 에이전트 런타임이 포함되어 있지 않습니다. 터미널은 컴퓨터에 이미 설치되고 로그인된 Claude Code 또는 Codex CLI를 워크스페이스 전용 PTY에서 실행합니다. 에이전트는 Atoll의 로컬 MCP 서버를 통해 열려 있는 캔버스를 확인하고 편집할 수 있습니다.

## 사전 요구 사항

세션을 열기 전에 사용할 CLI를 설치하고 인증합니다. 로그인 셸에서 명령을 찾을 수 있는지 확인합니다.

::: code-group

```bash [Claude Code]
command -v claude && claude --version
```

```bash [Codex]
command -v codex && codex --version
```

:::

Atoll은 어느 CLI도 설치하거나 해당 계정에 로그인하지 않습니다. 명령을 찾을 수 없다면 먼저 CLI 설치 또는 PATH를 수정합니다. 자세한 내용은 [문제 해결](/ko/help/troubleshooting)을 참고하세요.

::: warning
에이전트 터미널은 macOS에서만 검증되었습니다. CLI를 Unix 로그인 셸(`$SHELL -l -c`, 폴백 `/bin/zsh`)로 실행하므로 Windows에서는 아직 동작하지 않습니다.
:::

## 세션 시작, 전환, 종료

1. 워크스페이스를 열고 캔버스에서 **Open agent terminal**을 선택합니다.
2. 실행 중인 세션이 없으면 에이전트 선택기에서 **Claude Code** 또는 **Codex**를 선택합니다.
3. 터미널에 자연스럽게 입력합니다. 헤더에는 `Starting`, `Running`, `Exited` 중 하나가 표시됩니다.
4. 에이전트를 전환하기 전에 중지 컨트롤을 사용하여 실행 중인 프로세스를 종료합니다. 닫기 컨트롤로 패널을 숨길 수 있지만, 패널을 닫아도 세션은 종료되지 않습니다.

터미널은 워크스페이스당 하나의 세션만 사용합니다. Atoll은 사용자의 로그인 셸(`$SHELL -l -c`)을 통해 선택한 명령을 실행하므로 CLI의 일반 로그인 셸 PATH를 사용할 수 있습니다.

## 워크스페이스 파일 및 MCP 등록

PTY의 작업 디렉터리는 Atoll 애플리케이션 데이터 아래의 앱 관리 `workspaces/<workspace-id>/` 디렉터리입니다. 터미널을 열 때마다 Atoll은 다음 워크스페이스 로컬 파일을 새로 고칩니다.

- `.mcp.json`은 `http://127.0.0.1:17873/mcp/<workspace-id>?t=<session-token>`에서 `atoll-canvas`를 등록합니다.
- `CLAUDE.md`와 `AGENTS.md`에는 Claude Code와 Codex에 적용되는 동일한 Atoll 규칙이 들어 있습니다.
- `.claude/settings.json`에는 응답이 끝날 때 Atoll에 알리는 로컬 Stop 훅이 들어 있습니다.

Claude Code는 작업 디렉터리에서 프로젝트의 `.mcp.json`을 검색합니다. Codex는 세션별 `-c` MCP URL 재정의를 전달받습니다. 어느 방식도 에이전트의 전역 설정을 수정하지 않습니다. 생성된 프로젝트 파일이 워크스페이스 통합 지점입니다. 세션 토큰을 문서에 복사하거나 공유하지 마세요.

## 캔버스 노드 참조

하나 이상의 노드를 선택한 다음 **Cmd/Ctrl+C**를 누르거나 노드 툴바의 복사 동작을 사용합니다. 기본 클립보드 값은 `@atoll:node/<id>`와 같은 짧은 참조이며, 내장 에이전트는 `canvas_state`를 사용해 노드의 전체 컨텍스트를 확인합니다.

Atoll 외부의 터미널에서는 **Shift+Cmd/Ctrl+C**를 사용해 상세한 텍스트 형식으로 복사합니다. 이 형식에는 모델 또는 결과 컨텍스트와 가능한 경우 로컬 미디어 파일 경로가 포함됩니다. 이미지가 아닌 미디어는 에이전트가 직접 열도록 요청하지 않고 설명으로 표시됩니다.

## 가장 간단하게 사용할 수 있는 예

워크스페이스를 열고 에이전트 세션을 실행한 상태에서 다음을 입력합니다.

```text
이미지 모델을 추가하고 프롬프트 "달빛이 비치는 호수 위의 빨간 종이배"로 실행해 줘
```

에이전트는 캔버스를 확인하고 `list_models`를 사용해 모델을 찾은 다음 모델 노드를 만들고 프롬프트를 설정한 뒤 수행한 작업을 보고해야 합니다. 생성을 실행하려면 명시적으로 실행 요청을 추가하세요.

::: warning
공급자 크레딧이 소모됩니다. Atoll의 워크스페이스 규칙에 따라 사용자가 생성 실행을 명시적으로 요청한 경우에만 에이전트가 `canvas_run`을 호출해야 합니다. 에이전트에게 노드나 워크플로를 준비하라고 요청하는 것만으로는 실행을 허가한 것이 아닙니다.
:::

전체 도구 계약은 [Canvas MCP 도구](/ko/reference/mcp-tools)에 있습니다.
